# DSE Lab 5 - Streaming Service

ITESO - Sistemas Escalables

AWS Academy Learner Lab

## Description

This project implements a data streaming architecture using AWS services and Terraform.

## Architecture

Sensor Simulator
→ API Gateway
→ Lambda
→ Kinesis Data Streams
→ Lambda
→ DynamoDB / Amazon Redshift
→ Amazon Managed Grafana

## Technologies

- Terraform
- AWS API Gateway
- AWS Lambda
- Amazon Kinesis Data Streams
- Amazon DynamoDB
- Amazon Redshift Serverless
- Amazon Managed Grafana
- Amazon CloudWatch
- Python
